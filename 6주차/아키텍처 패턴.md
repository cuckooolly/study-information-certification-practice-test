# 아키텍처 패턴
## 아키텍처 패턴
- 아키텍처를 설계할 때 참조할 수 있는 전형적인 해결 방식 또는 예제
- 소프트웨어 시스템의 구조를 구성하기 위한 기본적인 윤곽을 제시
- 아키텍처 패턴에는 서브시스템들과 그 역할이 정의되어 있음
- 서브시스템 사이의 관계와 여러 규칙/지침 등이 포함됨
- 주요 아키텍처 패턴
  - 계층화 패턴 (Layered Pattern)
  - 클라이언트-서버 패턴 (Client-Server Pattern)
  - 이벤트 기반 패턴 (Event-Driven Pattern)
  - 마이크로서비스 아키텍처 (Microservices Architecture)
  - 파이프-필터 패턴 (Pipe-and-Filter Pattern)
  - MVC 패턴 (Model-View-Controller Pattern)

## 패턴의 종류와 예시
| 패턴 종류              | 설명                                        | 예시                                 |
|--------------------|-------------------------------------------|------------------------------------|
| 레이어 패턴             | 시스템을 여러 계층으로 나누어 각 계층이 특정 역할을 담당          | OSI 7계층 모델, 웹 애플리케이션 아키텍처          |
| 클라이언트-서버 패턴        | 클라이언트가 서버에 요청을 보내고 서버가 응답하는 구조            | 웹 애플리케이션, 데이터베이스 서버                |
| 파이프-필터 패턴          | 데이터가 여러 처리 단계를 거쳐 변환되는 구조                 | 데이터 처리 시스템, 컴파일러                   |
| 모델-뷰-컨트롤러 (MVC) 패턴 | 데이터 모델, 사용자 인터페이스, 제어 로직을 분리              | 웹 프레임워크 (예: Django, Ruby on Rails) |
| 마스터-슬레이브 패턴        | 하나의 마스터가 여러 슬레이브를 제어하는 구조                 | 데이터베이스 복제, 분산 컴퓨팅                  |
| 브로커 패턴             | 중개자가 클라이언트와 서버 간의 통신을 관리                  | 프록시 서버                             |
| 피어-투-피어 (P2P) 패턴   | 모든 노드가 동등한 역할을 하는 구조                      | 파일 공유 네트워크 (예: BitTorrent)         |
| 이벤트-버스 패턴          | 이벤트 메시지를 발행(Publish)하고 구독(Subscribe)하는 구조 | 메시지 큐 시스템 (예: RabbitMQ, Kafka)     |
| 블랙보드 패턴            | 여러 독립적인 컴포넌트가 공통의 데이터 저장소(블랙보드)를 통해 협력    | 음성 인식 시스템, 인공지능 시스템                |
| 인터프리터 패턴           | 특정 언어의 문법을 해석하고 실행하는 구조                   | SQL 파서, 수학식 평가기, 컴파일러              |
